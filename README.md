# CodeForge · API de Administración

API REST que gestiona los datos de la red social para desarrolladores: perfiles, proyectos, discusiones, seguimiento de usuarios, likes y mensajes privados.

**Despliegue:** https://codeforge-administracion.onrender.com

## Tecnologías
Java 21 · Spring Boot · Maven · PostgreSQL · Docker

## Endpoints principales
| Recurso | Ruta base |
|---|---|
| Usuarios | `/api/v1/usuarios` |
| Perfil | `/api/v1/profile` |
| Proyectos (incluye likes) | `/api/v1/projects` |
| Discusiones | `/api/v1/discussions` |
| Seguimiento | `/api/v1/following` |
| Mensajes privados | `/api/v1/mensajes` |
